# Mission Reflection

## 1. Why Is Automation Critical?

Automation is important when managing hundreds of cloud servers because performing tasks manually takes a lot of time and can cause human errors. Scripts and scheduled tasks help administrators perform repetitive work more consistently. For example, automated backups can help protect important files without requiring someone to remember to run them every day.

## 2. What Are the Potential Dangers of Automation?

Although automation saves time, it can also cause problems if a script contains an error. A destructive command scheduled to run on 1,000 servers could delete important files across many systems. This is why scripts should be tested carefully, permissions should be limited, and backups should be available before deploying automation on a large scale.

## 3. Bash Script vs. Docker Compose YAML

Writing a Bash script was different from creating a Docker Compose YAML file in Mission 6. A Bash script contains commands that execute tasks in sequence, such as creating folders and compressing files. Docker Compose uses YAML to define services, containers, and their configurations. Both tools help automate work, but they have different purposes.
