# Automation Research

## 1. Bash Script

A Bash script is a text file that contains commands the Bash shell can execute. The `#!/bin/bash` line at the top is called the shebang, and it tells the system to use Bash to run the script.

## 2. Variables

Variables store values such as folder paths and filenames. Using a variable like `$BACKUP_DIR` makes a script easier to maintain because you can update the folder path in one place.

## 3. Cron Job

A cron job is a scheduled task in Linux that runs a command or script at a specified time. It is useful in cloud operations because it can automate repeated tasks, such as backups, without requiring someone to run them manually.
