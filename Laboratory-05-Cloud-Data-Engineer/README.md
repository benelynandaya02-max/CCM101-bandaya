# Laboratory 05 – Cloud Data Engineer

## Mission Overview

This laboratory focused on cloud storage and the deployment of an S3-compatible object storage server using MinIO and Docker.

## Objectives

- Differentiate between Block, File, and Object Storage.
- Deploy MinIO using Docker.
- Access a cloud service through a web interface.
- Create a storage bucket and upload an object.
- Document cloud storage operations using Markdown.

## Tools Used

- KillerCoda
- Ubuntu
- Docker
- MinIO
- GitHub
- Markdown

## Skills Learned

I learned how to compare Block, File, and Object Storage. I also learned how to deploy MinIO using Docker, access the MinIO Web Console, create a bucket, upload an object, and document cloud storage operations using Markdown.
