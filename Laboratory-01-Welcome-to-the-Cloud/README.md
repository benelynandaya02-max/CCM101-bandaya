# Laboratory 01 – Welcome to the Cloud
## Mission Overview
This laboratory activity introduced me to the Linux environment and basic cloud computing tasks using the KillerCoda Playground. I also created a Github respository to serve as my Cloud Computing Portfolio.
## Objectives
- Access a cloud-based Linux environment.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a Github respository.
- Document technical work using Markdown.
## Activities Performed
1. Accessed the Ubuntu Linux environment using KillerCoda.
2. Created a new Linux user named bandaya.
3. Added the user to the sudo group.
4. Checked the current username, working directory, and hostname.
5. Gathered basic system information.
6. Created and organized Markdown files.
7. Created a Github repository for my Cloud Computing portfolio.
