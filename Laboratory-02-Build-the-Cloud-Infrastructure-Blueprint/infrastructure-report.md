# Infrastructure Report

## Operating System

The cloud environment uses Linux as its operating system.

## Kernel Version

The kernel version was checked using the `uname -r` command.

## CPU

The CPU information was checked using the `lscpu` command.

## Number of CPU Cores

The number of CPU cores was checked using the `nproc` command.

## Total RAM

The available RAM was checked using the `free -h` command.

## Disk Capacity

The disk capacity was checked using the `df -h` command.

## Mounted File Systems

Mounted file systems were checked using the `mount` command.

## Hostname

The hostname was checked using the `hostname` command.

## IP Address

The IP address was checked using the `hostname -I` command.
