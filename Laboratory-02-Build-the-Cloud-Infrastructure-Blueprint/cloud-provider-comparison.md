# Cloud Provider Comparison

## Infrastructure Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | VPC |
| Identity and Access Management | AWS IAM | Microsoft Entra ID | Cloud IAM |

## Questions and Answers

### 1. Which cloud provider offers the broadest range of services?

AWS offers a broad range of cloud services, including computing, storage, networking, databases, and security services.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would recommend Microsoft Azure because it works well with Microsoft products and services.

### 3. Which platform is widely recognized for AI, ML, and Kubernetes services?

Google Cloud Platform is widely recognized for its AI and machine learning services and provides Kubernetes support through Google Kubernetes Engine.

### 4. What similarities did you observe among the three cloud providers?

All three providers offer similar basic services such as compute, storage, networking, and identity management.
