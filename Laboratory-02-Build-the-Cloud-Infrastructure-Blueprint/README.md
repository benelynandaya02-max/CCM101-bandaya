# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Mission Overview

This laboratory activity focuses on understanding cloud infrastructure and its major components. I investigated a Linux cloud environment, researched major cloud providers, identified infrastructure resources, and designed a simple cloud infrastructure.

## Objectives

- Understand the major components of cloud infrastructure.
- Investigate hardware and software resources.
- Identify compute, storage, networking, and identity resources.
- Compare major cloud providers.
- Create a simple cloud infrastructure diagram.
- Document my findings using Markdown.
