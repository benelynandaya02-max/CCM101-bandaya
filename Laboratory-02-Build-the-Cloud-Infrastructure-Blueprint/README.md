# Laboratory Activity 2: Build the Cloud Infrastructure Blueprint

## Mission Overview

In this laboratory activity, I explored the basic components of cloud infrastructure using a Linux environment. The activity helped me understand how different resources such as compute, storage, networking, and operating systems work together in a cloud server. I also researched different cloud providers and created a simple cloud infrastructure design.

## Objectives

- Understand the basic components of cloud infrastructure.
- Explore the resources available in a Linux environment.
- Identify compute, storage, networking, and identity resources.
- Understand how cloud infrastructure components work together.
- Create technical documentation using Markdown.
- Organize laboratory files in my GitHub Cloud Computing Portfolio.

## Cloud Infrastructure Components

### Compute Resources

Compute resources provide the processing power needed to run applications, programs, and services.

### Storage Resources

Storage resources are used to save files, applications, databases, and other important data.

### Networking Resources

Networking resources allow servers, users, and other systems to communicate and connect through a network or the internet.

### Operating System

The operating system manages the hardware and software resources of the server. In this activity, Linux was used as the operating system.
