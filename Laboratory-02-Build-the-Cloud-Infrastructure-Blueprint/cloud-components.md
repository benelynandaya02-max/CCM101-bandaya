# Cloud Infrastructure Components

## 1. Compute Resource

The compute resource is the CPU or virtual machine provided by the Linux cloud environment. It provides processing power for running applications and commands.

## 2. Storage Resource

The storage resource is the disk space available in the Linux environment. It is used to store the operating system, applications, and files.

## 3. Networking Resource

The networking resource includes the network interface and IP address. It allows the cloud server to communicate with other systems and access the internet.

## 4. Operating System

The operating system used in the environment is Linux. It manages computer resources and provides commands needed to operate the cloud server.

## Relation to KillerCoda

These components can be observed in the KillerCoda Linux environment. The CPU provides computing power, the disk provides storage, networking allows communication, and Linux manages the overall system.
