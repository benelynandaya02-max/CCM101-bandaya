# Reflection

This laboratory activity helped me understand the basic components of cloud infrastructure and how they work together. I learned about compute, storage, networking, and operating systems.

I also learned how to investigate a Linux cloud environment and gather information about the operating system, CPU, memory, disk space, hostname, and IP address. Using Linux commands helped me better understand the resources available in a cloud server.

Another important thing I learned was the difference between major cloud providers such as AWS, Microsoft Azure, and Google Cloud Platform. Although they provide similar services, each platform has its own tools and features.

This activity also improved my skills in GitHub and Markdown. I learned how to create and organize files and folders, document my work, upload screenshots, and commit changes to my repository.

Overall, this laboratory activity gave me a better understanding of cloud infrastructure and the importance of proper documentation. It also helped me develop practical skills that I can use in future cloud computing activities.
