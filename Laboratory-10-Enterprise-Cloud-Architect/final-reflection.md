# Final Reflection

## My Cloud Computing Journey from Mission 1 to Mission 10

Throughout the CCM101 Cloud Computing Laboratory activities, I learned that cloud computing involves more than storing files online. It also includes managing serves, configuring infrastructure, deploying applications, protecting data, and automating tasks. Each laboratory helped me understand different responsibilities in managing a cloud environment.

In the earlier missions, I learned basic Linux commands and explored cloud infrastructure and cloud service providers. As continued, I gained knowledge about cloud-native technologies, storage, container deployment, system operations, and security. In Mission 9, I learned how Bash scripts and cron jobs can automate repetitive tasks such as creating backups. These activities helped me understand why automation and proper system configuration are important in cloud computing.

For Mission 10, the Enterprise Cloud Architect project brings these concepts together. The project requires planning an architecture, setting up a server, deploying an application with Docker Compose, configuring security, and preparing automated backups. I also learned that persistent storage is important because application data must be protected even when containers restart. Documentation is another important part of the project because other administrators need clear instructions to maintain and troubleshoot the system.

One challenge in this final mission is making sure that all components work together correctly. A successful deployment requires more than starting containers. Network access, firewall rules, database connectivity, storage, and backup procedures must also be tested. This helped me understand the importance of testing each component and checking the results instead of assuming that everything is working.

Overall, these laboratory activities have helped me develop my technical knowledge and problem-solving skills. I now have a better understanding of how cloud infrastructure can be deployed, secured, maintained, and automated. I will use these skills automated. I will use these skills in future IT projects and continue learning about cloud technologies.
