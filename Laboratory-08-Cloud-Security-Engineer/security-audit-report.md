## Security Audit Report

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users and applications only the permissions they need to perform their tasks. This is important in cloud environments because it helps prevent unauthorized access and reduces the damage that can happen if an account is compromised.

## 2. Attack Surface

The attack surface refers to all the possible points where an attacker could try to access or attack a virtual machine. Open ports, running services, weak passwords, and unnecessary software can increase the attack surface.

## 3. Default Deny Policy

A Default Deny policy blocks incoming network traffic unless a specific rule allows it. This is safer than blocking individual attackers because unknown or unauthorized connections are blocked automatically unless they are explicitly permitted.
