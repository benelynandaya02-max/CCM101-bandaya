## Mission Reflection

## 1. How Does a Host-Based Firewall Protect a Server?

A host-based firewall protects a server by controlling the network traffic entering and leaving the machine. Even if the physical network perimeter is breached, the firewall can still block unauthorized incoming connections based on its rules. This adds another layer of security to the server

## 2. Why Is Managing Open Ports Important?

Managing open ports is important because each open port can provide an entry point for attackers. If a service does not need to receive connections, its port should not be left open unnecessarily. Allowing only the required ports helps reduce the server's attack surface.

## 3. Why Is an Exposed Database Port Dangerous?

Leaving a database port, such as MySQL port 3306, open to the public internet can allow attackers to attempt unauthorized access, password attacks, or exploitation of database vulnerabilities. If the database is compromised, private information may be stolen, changed, or deleted. Database access should be restricted to trusted applications and authorized users.
