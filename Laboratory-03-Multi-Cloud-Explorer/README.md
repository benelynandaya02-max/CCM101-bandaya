## Cloud Platforms Explored

During this laboratory activity, I explored three major cloud computing platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). Each platform provides services for computing, storage, networking, databases, security, and other business needs.

### Amazon Web Services (AWS)

AWS is one of the major cloud computing platforms and offers a wide range of services for different organizations. Some of its core services include Amazon EC2 for virtual machines, Amazon S3 for object storage, Amazon RDS for databases, and Amazon VPC for networking. AWS is suitable for startups, businesses, and large organizations because its services can scale based on the needs of users.

### Microsoft Azure

Microsoft Azure is a cloud computing platform that is strongly integrated with Microsoft technologies. Its services include Azure Virtual Machines for computing, Azure Blob Storage for storage, Azure Virtual Network for networking, and Microsoft Entra ID for identity management. Azure is a good option for organizations that already use Windows Server, Microsoft 365, and other Microsoft products.

### Google Cloud Platform (GCP)

Google Cloud Platform provides cloud services for computing, storage, networking, databases, data analytics, artificial intelligence, and machine learning. Its core services include Compute Engine for virtual machines, Cloud Storage for object storage, Google Kubernetes Engine for containerized applications, and Cloud IAM for access management. GCP is commonly used for AI, machine learning, data analytics, and cloud-native applications.

## Cloud Platform Summary

Although AWS, Microsoft Azure, and GCP provide similar core cloud services, each platform has different strengths. AWS is known for its wide range of services, Azure is known for its integration with Microsoft technologies, and GCP is known for its strengths in data analytics, artificial intelligence, and Kubernetes.
