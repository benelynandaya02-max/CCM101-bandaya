|---|---|---|---|
| Launch Year | 2006 | 2010 | 2008 |
| Compute Service | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage Service | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking Service | Amazon VPC | Azure Virtual Network | Google Cloud VPC |

| Primary Strength | Wide range of services | Microsoft integration | AI and data analytics |
| Ideal Organizations | Startups and enterprises | Microsoft-based organizations | AI and cloud-native organizations |

## Questions and Answers

### 1. Which cloud provider offers the broadest range of services?
AWS offers a very broad range of cloud services for different IT needs. It provides many options for computing, storage, databases, networking, and other workloads.

### 2. Which provider best integrates with Microsoft technologies?
Microsoft Azure is the best choice for organizations already using Microsoft technologies. It works well with Windows Server, Microsoft 365, and Microsoft Entra ID.

### 3. Which provider is strongest in Artificial Intelligence and Kubernetes?
Google Cloud is known for its strengths in artificial intelligence, data services, and Kubernetes. Its services are useful for organizations building modern cloud-native and AI applications.

### 4. Which cloud platform would you personally choose and why?
I would choose AWS because it offers many cloud services and gives users flexible options for different projects. However, the best cloud provider should always depend on the needs of the organization.
