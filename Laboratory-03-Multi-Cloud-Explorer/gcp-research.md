# Google Cloud Platform (GCP)

## Brief Overview
Google Cloud Platform provides cloud services for computing, storage, networking, databases, data analytics, and artificial intelligence.

## Global Infrastructure
Google Cloud uses regions and zones located around the world to provide global cloud infrastructure.

## Cloud Management Console
The Google Cloud Console is a web-based interface used to manage projects and cloud resources.

## Four Core Services

### Compute Engine
Provides virtual machines for running applications.

### Cloud Storage
Provides object storage for files and application data.

### Google Kubernetes Engine (GKE)
Provides managed Kubernetes services.

### Cloud IAM
Provides identity and access management for cloud resources.

## Three Advantages
- Strong support for AI and data analytics.
- Strong Kubernetes capabilities.
- Global cloud infrastructure.

## Typical Enterprise Use Cases
GCP is used for AI, machine learning, data analytics, Kubernetes applications, and cloud-native development.
