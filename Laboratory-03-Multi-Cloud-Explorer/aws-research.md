# Amazon Web Services (AWS)

## Brief Overview
AWS is a cloud computing platform that provides services for computing, storage, databases, networking, security, and application development.

## Global Infrastructure
AWS provides cloud services through Regions and Availability Zones located around the world.

## Cloud Management Console
The AWS Management Console is a web-based interface used to manage AWS resources.

## Four Core Services

### Amazon EC2
Provides virtual servers for running applications.

### Amazon S3
Provides object storage for files and data.

### Amazon RDS
Provides managed relational databases.

### Amazon VPC
Provides isolated virtual networking for cloud resources.

## Three Advantages
- Wide range of cloud services.
- Flexible and scalable infrastructure.
- Global infrastructure.

## Typical Enterprise Use Cases
AWS can be used for web applications, databases, storage, backups, analytics, and disaster recovery.
